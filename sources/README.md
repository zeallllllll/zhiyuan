## 解析说明

- 中考 JSON 结构按 `exam / city / years / districts / schools` 组织，学校内包含 `scores`、`subjects`、`sourceFiles`、`sourceUrls`。
- `sources/parsed/` 保存 PDF 转文本的中间文件，便于人工校对。
- 当前中考页仍以 2022-2025 年“名额分配到区”连续口径展示；2021 年为旧中招批次口径，未混入本表。
- 高考 580 分及以上专业组官方不公开具体投档分，本项目保留为“580分及以上”。
